# Contributing

Thanks for contributing to this AAPL options tracker repo.

## Day-to-day additions

1. Pull fresh live data (Yahoo Finance) for the current share price and the nearest option expirations.
2. Add or update the tracking file (`expirations.md`) with the company snapshot, the expiration map, and per-expiration stats (ATM strike, highest-open-interest call strike, highest-open-interest put strike).
3. Open a branch (e.g. `add-<topic>`) off `main`, commit the file, and open a pull request.

## Getting started

- Keep all data sourced from live market feeds rather than past copies.
- Follow the repo's formatting for the stats tables.
